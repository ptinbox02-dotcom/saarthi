# The lesson factory

Manim scenes, narration timing, splicing and the eval gate — everything that turns a
script into a rendered micro-lecture.

**This code lived outside version control until now.** It sat in a sibling directory on
one laptop, with four `.bak` files as its entire history, while eleven files in the
lesson pipeline reached into it by path. The student app was safe on GitHub; the ability
to make another lesson was not. That is why it is here.
