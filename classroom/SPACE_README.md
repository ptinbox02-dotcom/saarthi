# Saarthi classroom

A pre-recorded JEE physics micro-lecture that a student can interrupt. Raise a hand and
the recording pauses at the end of the sentence, the board comes up, and a grounded
tutor answers out loud in Hinglish or Gujlish while writing the answer in chalk.

The board is two-way: draw on it, type on it, drop an image on it, or highlight part of
it and ask about that specific line.

**This Space is passcode-protected.** Every question spends a Gemini Live turn on a
billed key, so the page, the API, the lesson videos and the socket all require it, and
there is a shared daily budget for answers.
